# 🏋️ PlanixFit - Aplicación de Rutinas de Ejercicio

PlanixFit es una aplicación de seguimiento de rutinas de ejercicio que ayuda a los usuarios a mantener sus entrenamientos organizados. La aplicación muestra automáticamente la rutina del día actual, guía al usuario a través de cada ejercicio con temporizadores precisos, y proporciona períodos de descanso entre ejercicios con cuenta regresiva.

## 🛠️ Tecnologías Utilizadas

- **Angular 20**: Framework principal para el desarrollo frontend
- **TypeScript 5.8**: Lenguaje de programación tipado
- **Tailwind CSS 4.1**: Framework de CSS para el diseño de la interfaz
- **RxJS 7.8**: Biblioteca para programación reactiva
- **Angular Signals**: Para manejo de estado reactivo
- **@ng-select/ng-select**: Componente de selección avanzado

## 🚀 Instalación y Ejecución

### Requisitos Previos

- Node.js (versión 18 o superior)
- npm (versión 9 o superior)

### Clonar el Repositorio

```bash
git clone https://github.com/tu-usuario/planix-fit.git
cd planix-fit
```

### Instalar Dependencias

```bash
npm install
```

### Ejecutar en Modo Desarrollo

```bash
npm start
```

La aplicación estará disponible en `http://localhost:4200/`.

### Compilar para Producción

```bash
npm run build
```

Los archivos compilados se generarán en el directorio `dist/`.

## 📱 Características Principales

- Seguimiento de rutinas por día de la semana
- Temporizadores para ejercicios y descansos
- Notificaciones sonoras para cambios de ejercicio
- Interfaz intuitiva y responsive
- Personalización de rutinas y ejercicios
